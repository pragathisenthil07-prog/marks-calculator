# Marks Calculator

A simple Python program that takes a student's name and marks in different subjects, then works out the total, average and grade.

## What it does
- Asks for the student's name and number of subjects
- Takes marks for each subject
- Calculates total and average
- Gives a grade based on the average (O, A+, A, B or C)

## How to run
1. Install Python 3
2. Download marks_calculator.py
3. Run: python marks_calculator.py
4. Enter the details when asked

## Grading
- 90 and above: O
- 80 to 89: A+
- 70 to 79: A
- 60 to 69: B
- Below 60: C
